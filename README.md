# Pokedex-web

A simple Pokedex application built with React and TypeScript, using the [PokeAPI](https://pokeapi.co/) as its data source. This is a personal learning project, originally part of a bigger private repository of my React learning practice and later extracted to make public.

This project is built with React, TypeScript, and Vite.

## Getting started

```bash
npm install
npm run dev
```

Other available scripts:

- `npm run build` — type-check and build for production
- `npm run lint` — run ESLint
- `npm run preview` — preview the production build locally
